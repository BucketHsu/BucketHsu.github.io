當文字檔中有多行包含特定字串時，可以使用 Notepad++ 的正規表示式一次刪除整行，再視需要清除留下的空白行。

== 開啟取代視窗

使用下列任一方式開啟取代功能：

* 功能表選擇 `搜尋` → `取代`
* 使用快捷鍵 kbd:[Ctrl+H]

搜尋模式必須選擇 `正規表示式`。

== 步驟一：刪除包含特定字串的整行

在「尋找內容」輸入：

[source,regex]
----
.*pattern.*
----

將 `pattern` 替換成實際要搜尋的文字，並將「取代為」保持空白，再按下「全部取代」。

例如要刪除所有包含 `MitacStatementProxy` 的行：

[source,regex]
----
.*MitacStatementProxy.*
----

此表示式的意思是：

[cols="25%,75%", options="header"]
|===
|表示式 |說明

|`.*`
|比對任意字元零次以上。

|`pattern`
|要尋找的特定字串。

|`.*pattern.*`
|比對整行中只要包含指定字串的內容。
|===

WARNING: 如果特定字串本身含有 `.`, `(`, `)`, `[`, `]`, `+`, `*`, `?` 等正規表示式特殊字元，應先使用反斜線跳脫。例如要搜尋 `a.b`，可寫成 `a\.b`。

== 步驟二：刪除空白行

若完成第一步後留下空白行，可以再次使用取代功能。

「尋找內容」輸入：

[source,regex]
----
^[\s]*$[\n\r]*
----

「取代為」保持空白，再按下「全部取代」。

此表示式可拆解為：

[cols="30%,70%", options="header"]
|===
|表示式 |說明

|`^`
|行開頭。

|`[\s]*`
|零個以上的空白字元。

|`$`
|行結尾。

|`[\n\r]*`
|零個以上的換行字元。
|===

也可以使用較常見、較精簡的寫法：

[source,regex]
----
^\h*\R
----

其中 `\h*` 代表零個以上的水平空白字元，`\R` 代表任一種換行符號。

== 操作注意事項

* 建議先備份檔案，或確認可以使用 kbd:[Ctrl+Z] 還原。
* 搜尋模式必須選擇 `正規表示式`，不能使用「一般」模式。
* 若只想刪除完全等於某個字串的行，不要使用前後的 `.*`。
* 大量取代前可先按「找下一個」，確認表示式確實命中預期內容。

== 完全等於指定字串的行

若只想刪除內容完全等於 `pattern` 的行，可使用：

[source,regex]
----
^pattern\R?
----

若該行前後可能有空白，可使用：

[source,regex]
----
^\h*pattern\h*\R?
----
