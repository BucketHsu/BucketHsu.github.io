本頁整理 Windows 環境下 Eclipse、IntelliJ IDEA 與 Visual Studio Code 的常用快捷鍵，並依功能分類，方便在不同 IDE 間切換時快速查找。

[NOTE]
====
快捷鍵可能因 IDE 版本、Keymap、作業系統、語言套件或擴充套件而不同。本頁以常見的 Windows 預設配置為主，實際結果應以目前 IDE 的快捷鍵設定畫面為準。
====

== 使用前注意事項

=== 快捷鍵可能被作業系統或其他軟體占用

例如輸入法、顯示卡工具、遠端桌面軟體或螢幕錄影工具，都可能攔截 IDE 快捷鍵。

遇到快捷鍵無反應時，可依序檢查：

. IDE 是否已綁定該快捷鍵。
. 是否存在同一快捷鍵的衝突設定。
. 作業系統或常駐工具是否先攔截按鍵。
. 當前焦點是否位於編輯器、終端機或工具視窗。

=== IntelliJ IDEA Keymap

IntelliJ IDEA 可切換不同 Keymap，例如：

* Windows
* Eclipse
* Visual Studio
* VS Code

設定位置：

[source,text]
----
Settings → Keymap
----

若從 Eclipse 移轉到 IntelliJ IDEA，可先使用 Eclipse Keymap 降低轉換成本，再逐步改回 IntelliJ IDEA 預設配置。

=== VS Code 快捷鍵受擴充套件影響

VS Code 的 Java、Git、Vim、Emacs 等擴充套件可能覆寫或新增快捷鍵。

設定位置：

[source,text]
----
File → Preferences → Keyboard Shortcuts
----

也可使用：

[source,text]
----
Ctrl + K，接著 Ctrl + S
----

== 如何查目前 IDE 的實際快捷鍵

=== Eclipse

[source,text]
----
Window → Preferences → General → Keys
----

可依 Command、Binding 或 Category 搜尋。

=== IntelliJ IDEA

[source,text]
----
File → Settings → Keymap
----

可搜尋動作名稱、查看衝突、增加第二組快捷鍵或切換 Keymap。

=== VS Code

[source,text]
----
File → Preferences → Keyboard Shortcuts
----

可查看：

* Command ID
* 現有快捷鍵
* `when` 條件
* 衝突來源
* 使用者自訂 `keybindings.json`

== Keymap 移轉建議

=== 從 Eclipse 轉 IntelliJ IDEA

可優先記住：

* kbd:[Shift+Shift]：Search Everywhere。
* kbd:[Alt+Enter]：快速修正。
* kbd:[Ctrl+Alt+L]：格式化。
* kbd:[Shift+F6]：重新命名。
* kbd:[Alt+F7]：查看使用位置。

=== 從 IntelliJ IDEA 轉 VS Code

可優先記住：

* kbd:[Ctrl+P]：快速開檔。
* kbd:[Ctrl+Shift+P]：命令面板。
* kbd:[Ctrl+Shift+F]：全工作區搜尋。
* kbd:[Ctrl+.]：快速修正。
* kbd:[F12]：跳到定義。

== 維護原則

* 快捷鍵表應標示適用作業系統與 Keymap。
* 新增快捷鍵前應先確認是否為 IDE 預設值。
* 擴充套件專屬快捷鍵應註明所需擴充套件。
* 避免把多個不同功能合併成同一列。
* 遇到版本差異時，以動作名稱比按鍵組合更可靠。
* 調整自訂快捷鍵後，建議同步備份 IDE 設定。
