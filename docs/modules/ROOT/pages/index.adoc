== 說明

這裡整理可公開的工程筆記，內容以日後查閱、問題排查與實務判斷為主。

首頁是本站的主要入口。可直接依下方主題選擇文件，也可以使用左側導覽快速切換分類。

首頁文件分類原則上應與左側 `nav.adoc` 保持一致；新增正式文件時，若已加入左側導覽，也應同步加入首頁對應分類。
