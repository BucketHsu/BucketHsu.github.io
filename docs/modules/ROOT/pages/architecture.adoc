== 文件站結構

本站以 Antora 作為主要文件網站產生工具，並由 GitHub Pages 發布靜態網站。

[cols="30%,70%", options="header"]
|===
|位置 |用途

|`docs/antora.yml`
|定義 Antora component 名稱、標題、版本與導覽檔。

|`docs/modules/ROOT/nav.adoc`
|定義左側導覽結構。

|`docs/modules/ROOT/pages/`
|放置主要 AsciiDoc 文件內容。

|`docs/modules/ROOT/assets/`
|放置圖片、樣式與其他靜態資源。

|`antora-playbook.yml`
|定義站台標題、來源位置、UI bundle 與 AsciiDoc 屬性。

|`.github/workflows/pages.yml`
|負責建置文件並部署到 GitHub Pages。
|===

== 建置與發布流程

本站保留 Maven AsciiDoc 與 Antora 兩條建置路徑。

. Maven 先驗證既有 AsciiDoc HTML 產出。
. Antora 產生 GitHub Pages 使用的多頁文件網站。
. GitHub Actions 將 `target/generated-docs/site/` 發布到 GitHub Pages。

主要指令請參考 repository 根目錄的 `README.adoc`。

== 內容維護原則

新增或調整文件時，建議遵守下列原則：

* 依主題放在合適目錄，避免把所有筆記集中在單一文件。
* 重要入口頁應同步更新首頁與側邊導覽。
* 技術內容以可查閱、可排查、可重複操作為主。
* 文件格式與用語請參考 xref:contributing/writing-style.adoc[文件撰寫規範]。
