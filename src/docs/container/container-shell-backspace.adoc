== 問題

使用 `sh` 進入 container 後，可能出現下列狀況：

* Backspace 無反應。
* Backspace 顯示 `^H` 或 `^?`。
* 無法正常修改指令。

== 原因

常見原因：

* `sh`，例如 busybox / dash，互動能力較弱。
* `stty erase` 設定不一致。
* `TERM` 環境不匹配。

== 解法

=== 優先使用 bash

[source,bash]
----
docker run -it --rm --name maven <image> bash
----

=== sh 下修正 erase

[source,bash]
----
stty erase ^H
----

或：

[source,bash]
----
stty erase ^?
----

=== 必要時設定 TERM

[source,bash]
----
export TERM=xterm
----

== 建議

若 container 常需要互動操作，建議在 Dockerfile 直接安裝 `bash`。
