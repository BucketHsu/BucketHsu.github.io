== 本機編譯

[source,bash]
----
mvn -B -DskipTests generate-resources
----

編譯後 HTML 會產生在：

[source,text]
----
target/generated-docs/
----

== GitHub Pages

推送到 `main` 後，GitHub Actions 會編譯 AsciiDoc 並發布 `target/generated-docs/` 到 GitHub Pages。
