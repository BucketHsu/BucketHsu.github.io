這個 repository 是 `https://novice-engineer.github.io/` 的技術筆記來源。

== 文件網站入口

* GitHub Pages：`https://novice-engineer.github.io/`
* Antora 首頁：`docs/modules/ROOT/pages/index.adoc`
* Antora 導覽：`docs/modules/ROOT/nav.adoc`
* 文件撰寫規範：`docs/modules/ROOT/pages/contributing/writing-style.adoc`

== 建置路徑

目前文件同時保留兩條建置路徑：

* Maven + `asciidoctor-maven-plugin` + `spring-asciidoctor-backends`：
  產生既有單頁 HTML 文件，方便維持原本 AsciiDoc 輸出流程。
* Antora：
  產生多頁文件網站，作為 GitHub Pages 的站點輸出。

== 快速啟動

[source,bash]
----
npm ci
mvn -B -DskipTests generate-resources
npm run docs:site
----

== 本機建置

只產生 Maven AsciiDoc HTML：

[source,bash]
----
mvn -B -DskipTests generate-resources
----

只產生 Antora 文件網站：

[source,bash]
----
npm ci
npm run docs:antora
----

完整產生 GitHub Pages 使用的站點內容：

[source,bash]
----
npm run docs:site
----

建置後會產生：

[source,text]
----
target/generated-docs/asciidoc/
target/generated-docs/site/
----

== GitHub Pages

推送到 `main` 後，GitHub Actions 會先驗證 Maven AsciiDoc 建置，再建立 Antora 文件網站，最後發布 `target/generated-docs/site/` 到 GitHub Pages。

workflow 位置：

[source,text]
----
.github/workflows/pages.yml
----

== 新增或調整文件

新增文件時，通常需要同步確認：

* 文件是否放在 `docs/modules/ROOT/pages/` 底下的合適分類目錄。
* `docs/modules/ROOT/nav.adoc` 是否需要加入導覽連結。
* `docs/modules/ROOT/pages/index.adoc` 是否需要加入首頁分類表格。
* 文字風格是否符合文件撰寫規範。
